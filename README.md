# Эксперт Байк - Сайт аренды электровелосипедов

Сайт для аренды и ремонта электровелосипедов в Краснодаре с админ-панелью.

## 🚀 Возможности

- ✅ Каталог электровелосипедов с ценами
- ✅ Админ-панель для управления контентом
- ✅ Хранение изображений в IndexedDB (до 100MB)
- ✅ Адаптивный дизайн (мобильная версия)
- ✅ Информация о ремонте электровелосипедов
- ✅ Контактная информация

## 🔐 Доступ к админ-панели

- URL: `ваш-сайт/#/admin`
- Пароль: `admin`

## 📸 Хранилище изображений

Изображения сохраняются локально через **IndexedDB** — встроенное хранилище браузера.

### Преимущества IndexedDB:
- ✅ **Не требует настройки** — работает из коробки
- ✅ **Большой объем** — до 50-100MB (зависит от браузера)
- ✅ **Быстрая загрузка** — изображения загружаются мгновенно
- ✅ **Работает оффлайн** — не требует интернет-соединения
- ✅ **Безопасно** — данные хранятся только в вашем браузере

### Как это работает:
1. При загрузке изображения оно сохраняется в IndexedDB
2. В localStorage хранится только ссылка на изображение
3. При отображении изображение загружается из IndexedDB
